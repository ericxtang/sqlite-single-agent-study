# Historical source and provenance

These are selected original frozen files and aggregate records, retained for audit context. They are not runnable entry points for this public checkout; use `replication/` and the root README.

The original v1 seal references the original machine, model catalog, private audits and corpus checkout. Some of those inputs are intentionally not public, so this repository does not claim complete verification of the original seal on another machine. `bundled-originals.json` checks byte-identical included files. The original protocol and scoring files at the root are also unchanged.

The usage ledger is a sanitized export: identifiers are removed, numeric fields and reconciliation outcomes are preserved. Raw sessions and response-level reasoning are not included. This limitation is explicit in the public report.
